## 5. 크롤링/조회 팁

### URL 유효성 검증

```python
# validate_links.py 핵심 로직
import requests

def validate_property_url(url: str) -> bool:
    """매물 URL이 실제 매물 페이지인지 검증"""
    resp = requests.get(url, timeout=10)
    if resp.status_code != 200:
        return False
    # 200이어도 컨텐츠 검증 필수
    content = resp.text.lower()
    keywords = ['매매가', '전용면적', '대지면적', '평', '억', '만']
    return any(kw in content for kw in keywords)
```

### 실거래가 조회 시 주의

- 최근 3년 데이터만 유효 (시장 변동 반영)
- 동일 단지/유형 필터링 필수
- 이상치(급매, 특수거래) 제외 후 중앙값 사용
