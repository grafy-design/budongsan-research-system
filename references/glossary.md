# 약어·전문용어 용어집

> 보고서 전반(DOCX·랜딩·차트)에서 사용되는 약어를 전부 풀어쓰기 위한 기준.
> 빌더는 본 문서의 치환 규칙에 따라 산출물을 재생성해야 함.

---

## 1. 점수 차원 (8개) — 핵심 약어

| 약어 | 풀어쓴 이름 | 부가 설명 (툴팁·인덱스용) | 측정 4항목 |
|------|------------|--------------------------|----------|
| **LOC** | 입지·접근성 | 매물까지의 이동 편의 | 대중교통, 자차, 보행성, 주차 |
| **PRC** | 가격 적정성 | 실거래 대비 가격 포지셔닝 | 평당가 percentile, 공시지가 추이, 호가 대비, 동급 비교 |
| **PHY** | 물리적 상태 | 건물·설비 컨디션 | 준공년수, 구조, 마감, 설비 |
| **REG** | 법적·규제 | 활용 가능성에 영향 | 용도변경, 건폐·용적률 여유, 문화재 제약, 심의 통과 확률 |
| **MKT** | 상권·문화 인프라 | 주변 동네 맥락 | 도보권 카페, 문화시설, 유동인구, 임대료 안정성 |
| **FIT** | 목적 적합도 | 대표 용도와의 매칭 | 갤러리/카페/모임 매칭, 본채·별채 활용, 정원, 차별 자산 |
| **SCR** | 희소성·미래가치 | 공급 제약과 스토리 | 동급 매물 빈도, 공급 제약, 스토리, 5년 잠재 |
| **FIN** | 재무·수익성 | 비용·수익 효율 | 보유세/매매가, NOI/매매가, 취득세 효율, 담보 가치 |

## 2. 기타 업계 약어·전문용어

| 약어/용어 | 풀어쓴 이름 | 부가 설명 |
|----------|------------|----------|
| **CMA** | 비교 시장 분석 | Comparative Market Analysis. 동급 매물 실거래와의 가격 비교 |
| **ROI** | 투자 수익률 | Return On Investment. 투자금 대비 수익 비율 |
| **NOI** | 순영업수익 | Net Operating Income. 임대료 수익에서 운영비를 뺀 연간 순수익 |
| **GB** | 개발제한구역 | Green Belt. 자연환경 보전을 위해 개발이 제한된 구역 |
| **RC조** | 철근콘크리트 구조 | Reinforced Concrete. 철근을 넣어 보강한 콘크리트 구조 |
| **평당가** | 3.3㎡당 가격 | 전용면적 3.3㎡(1평) 기준 단가 |
| **percentile** | 백분위 | 동급 모집단에서의 상대적 순위 (예: 70 percentile = 상위 30%) |
| **심의** | 건축·문화재 심의 | 인허가 전 행정 심사 절차 |
| **호가** | 매도 희망가 | 매도인이 제시한 판매 희망 가격 |
| **공시지가** | 공시지가 | 국토교통부가 매년 공시하는 토지 기준가 |
| **용적률** | 용적률 | 대지면적 대비 건물 연면적 비율 |
| **건폐율** | 건폐율 | 대지면적 대비 건축면적 비율 |

## 3. 빌더용 Python 치환 규칙

```python
import re

# 점수 차원 8개
DIMENSION_REPLACEMENTS = {
    'LOC': '입지·접근성',
    'PRC': '가격 적정성',
    'PHY': '물리적 상태',
    'REG': '법적·규제',
    'MKT': '상권·문화',
    'FIT': '목적 적합도',
    'SCR': '희소성·미래가치',
    'FIN': '재무·수익성',
}

# 기타 업계 약어
EXTRA_REPLACEMENTS = {
    'CMA': '비교 시장 분석',
    'ROI': '투자 수익률',
    'NOI': '순영업수익',
    'GB':  '개발제한구역',
}

def expand_abbreviations(text: str) -> str:
    """단어 경계를 엄격히 지켜 치환. LOCAL·LOCK 같은 건 제외."""
    for abbr, full in {**DIMENSION_REPLACEMENTS, **EXTRA_REPLACEMENTS}.items():
        text = re.sub(rf'\b{abbr}\b', full, text)
    return text
```

### 치환 주의사항

1. **단어 경계 필수**: `\b`를 사용해 `LOCAL`, `LOCK`, `PRCE` 등의 오치환 방지
2. **첫 등장 규칙**: 본문 첫 등장 시 `입지·접근성(LOC)` 형태로 병기, 이후는 풀어쓴 이름만 사용
3. **차트 라벨**: matplotlib PNG 재생성 시에도 풀어쓴 이름 사용 (xticks, legend 전수 교체)
4. **RC조**: `\bRC조\b`가 아닌 `RC조` 단독 치환 권장 (한글 경계 이슈)

## 4. 치환 대상 범위 (전수)

치환은 다음 **모든 곳**에 적용해야 함:

| 대상 | 비고 |
|------|------|
| 본문 텍스트 | 문단 내 약어 |
| 표 셀 내용 | 모든 표의 모든 셀 |
| 이미지 캡션 | 차트·사진 캡션 |
| 이미지 alt 텍스트 | 접근성용 alt |
| matplotlib 라벨 | xticks, yticks, legend, title |
| 빌드 스크립트 하드코딩 | 스크립트 내 문자열 리터럴 |
| 랜딩 HTML 텍스트 | 제목, 라벨, 툴팁 |
| VTT 자막 텍스트 | 영상 자막 내 약어 |
