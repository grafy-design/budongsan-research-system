# 리서치 에이전트 프롬프트 — 5개 영역 병렬 파견

> **역할**: 매물의 매입 타당성을 5개 영역에서 심층 조사하는 리서치 에이전트팀.
> **산출물**: `research/01_usage_change.md` ~ `research/05_rebuild_cost.md`
> **데이터 소스**: [references/data_sources.md](../references/data_sources.md)
> **공통 규칙**: 모든 수치에 공식 URL 첨부 필수. 신뢰도 ★ 표기 필수. 추정치는 근거 명시.

---

## 공통 변수 (project_config.json 에서 주입)

```
{{address}}        — 매물 주소 (예: 서울시 종로구 부암동 325-3)
{{price_eok}}      — 매매가 (억 단위, 예: 32)
{{area_m2}}        — 대지면적 ㎡ (예: 605)
{{area_pyeong}}    — 대지면적 평 (예: 183)
{{floor_area_m2}}  — 연면적 ㎡ (예: 199.03)
{{floor_area_py}}  — 연면적 평 (예: 60)
{{built_year}}     — 준공연도 (예: 2007)
{{structure}}      — 구조 (예: RC조 지하1 지상2)
{{purpose}}        — 목적 (예: ["갤러리", "카페", "모임"])
{{source_url}}     — 매물 출처 URL
{{img_dir}}        — 임장 사진 경로
```

---

## 공통 작성 규칙

1. **핵심 요약 테이블** — 문서 최상단에 항목·결론·신뢰도(★1~5) 표 필수
2. **법적 근거** — 법령명 + 조항 + law.go.kr 링크
3. **수치 출처** — 모든 금액·면적·비율에 공식 URL 또는 데이터 소스 명시
4. **신뢰도 등급** — S(공공/공식) / A(뉴스·기관) / B(인접추정) / C(현장판단)
5. **사전 확인 필요 사항** — 담당 관청 + 전화번호 + 질의 방법 기재
6. **약어 금지** — LOC, PRC, PHY 등 약어 본문 노출 0. 한글 풀어쓰기
7. **산출물 경로** — 각 에이전트별 지정 경로에 저장
